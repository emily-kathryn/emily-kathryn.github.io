Undergraduate research

Mapping Scientific Literature with Topological Data Analysis

CBU AI & Machine Learning Lab · May 2026 – Present

Analyzing 3,490 scientific publications represented by 1,024-dimensional language-model embeddings to study relationships among research topics, papers, and researchers. I use Mapper, resampling experiments, and persistent homology to examine graph structure and coverage.

Methods & details

Built Mapper graphs using cosine-based DBSCAN and several analytical lenses, including PCA, neighborhood density, KDE, and local outlier factor. Designed 30-run resampling experiments and cross-lens overlap comparisons to examine how analysis choices affect graph structure and coverage.

Applied persistent homology to study connected components and cycles, and extended the analysis to approximately 1,000 researchers. This work also includes technology readiness assessments of research publications.

Python · Mapper · Persistent homology · Scientific embeddings

Machine learning research project

Marine Debris Detection with Deep Learning

California Baptist University · September 2026 – Present

Developing computer vision pipelines for identifying debris in underwater imagery, connecting machine learning with environmental monitoring and marine conservation. Initial results are a validation baseline; external evaluation is ongoing.

Methods & details

Prepared TrashCan and J-Litter images and annotations for binary classification in PyTorch. An initial ResNet-18 validation baseline achieved 91.52% accuracy, 89.01% precision, 86.51% recall, and an F1 score of 0.8774.

Continuing work includes evaluating independent underwater datasets and developing object detection pipelines. The initial validation results are a baseline; external evaluation is ongoing.

PyTorch · Computer vision · Environmental data

C++ scientific computing

Relativity Dashboard / Mission Control

Independent technical project · Started April 2026

Built a native C++ simulator and interactive 3D visualizer for one-way spacecraft missions in special relativity. A reusable simulation library integrates relativistic equations of motion with RK4 to compare Earth-frame coordinate time and traveler proper time.

Methods & details

The visualizer includes mission playback, trajectory exploration, and reference-frame comparisons.

The current model assumes flat spacetime and a symmetric acceleration-and-braking trip between stationary endpoints. A command-line interface supports repeatable calculations and CSV exports.

C++ · Numerical integration · 3D visualization · Scientific computing

Marine science & data visualization

Marine Migration Visualizer

Independent scientific computing project

Exploring hawksbill and green turtle movements in the Chagos Archipelago, western Indian Ocean. The source dataset contains 88,727 valid, visible GPS observations from 23 turtles; analysis scripts also ingest source-flagged observations.

Methods & details

Implemented Haversine distances between consecutive locations, daily distance totals, and per-turtle movement summaries. Outlier filtering excludes days above 150 km or three standard deviations above each turtle’s mean from cleaned summaries.

The project also generates a Folium map. This preview highlights two recorded tracks across the Indian Ocean and three local tracks around Diego Garcia; lines break at gaps over 48 hours or steps over 200 km. The analysis scripts ingest all valid records, including source-flagged observations; the visible-observation count describes the source dataset.

Python · pandas · Haversine distance · Folium
