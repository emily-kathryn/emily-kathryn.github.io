# Academic research portfolio

This is a single-file website for GitHub Pages. Before publishing, review all descriptions and links and confirm you are comfortable making them public.

## Publish

1. Create a **public** repository named `emily-kathryn.github.io` in the GitHub account `emily-kathryn`. Initialize with a README so that a `main` branch exists.
2. Upload `index.html` to the repository root using **Add file → Upload files**, then commit it to `main`.
3. Open **Settings → Pages**. Set **Source** to `Deploy from a branch`, branch `main`, folder `/(root)`, and click **Save**.
4. Visit `https://emily-kathryn.github.io` once GitHub finishes publishing.

## Customize

- All content and CSS are in `index.html`.
- Change text and research descriptions as needed.
- No private research data, repository content, or unapproved images are included.
- The page currently has GitHub and LinkedIn contact links. Add an academic email and an approved CV PDF when ready.
- The abstract graphics are decorative CSS shapes, not research figures.
