01 / Research

Selected work

My projects explore computer vision, structure in high-dimensional scientific data, and computational approaches to real-world research problems.

RESEARCH PROJECT 01

Marine Debris Detection with Deep Learning

Developing computer vision pipelines to identify marine debris in underwater imagery. My work includes image classification with ResNet-18 and object detection with YOLO, using marine debris datasets to study how computational tools can support environmental observation.

Computer Vision · Deep Learning · Environmental Data
Underwater image analysis

RESEARCH PROJECT 02

Topological Data Analysis of Scientific Literature

Investigating the structure of scientific paper embeddings using dimensionality reduction, clustering, and Mapper. This work examines how choices in data representation and analysis affect the patterns visible in complex research datasets.

Topological Data Analysis · Scientific Embeddings · Python
Patterns in complex data

ENGINEERING PROJECT

Autonomous Quadruped Robotics

Contributing to an interdisciplinary robotics capstone through path planning, replanning around obstacles, and simulation and control infrastructure for an autonomous quadruped.

Robotics · Path Planning · Simulation
Navigation and autonomy
